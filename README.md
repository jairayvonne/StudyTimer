Time Lock
-It helps students stay focused and manage study sessions effectively using customizable timers.

Features
-Sign-up, login, and logout using email/username and password
-Customizable study timer
-Adjustable break intervals
-Time controls
-Alert/notification when a study or break finishes

How to install and run
1.Open your mobile browser(ex.Google Chrome).
2.Open https://studytimer-67231.web.app in your mobile browser.
3.Tap the browser menu ":" (3 dots on the top-right corner) and select Install or Add to Home Screen.
4. After installing the app, open Time Lock from your home screen and sign in with your account.
